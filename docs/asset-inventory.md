# Asset inventory

Every font, icon and image the website uses, where it came from, and its license or permission status. "Organization-provided" means the file was supplied by Katoto Project in this project folder; Katoto's permission to publish it, and the consent of people pictured, is recorded as **to confirm** where no written record exists.
